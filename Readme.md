# Olist E-Commerce SQL Analysis

## 📌 Overview
This project is an end-to-end SQL analysis performed on the **Olist Brazilian E-commerce public dataset**.  
The goal of this project is to understand customer behavior, order trends, revenue patterns, and delivery performance using clean, readable SQL queries.

The analysis focuses on answering real business questions using clear and understandable SQL rather than unnecessary complexity.

---

## 📊 Dataset
- **Source:** Brazilian E-Commerce Public Dataset by Olist
- **Records:** ~100,000 orders
- **Tables used:**
  - `olist_orders_dataset`
  - `olist_customers_dataset`
  - `olist_order_items_dataset`
  - `olist_order_payments_dataset`
  - `olist_order_reviews_dataset`
  - `olist_products_dataset`
  - `product_category_name_translation`

---

## 🛠 Tools & Technologies
- **Database:** MySQL
- **Language:** SQL
- **Environment:** MySQL Workbench
- **Version Control:** Git & GitHub

---

## 🔍 Analysis Performed

The SQL analysis is available in:
- **`olist_sql_analysis.sql`**

### Key areas covered:
- Orders and customers overview
- Order status distribution
- Revenue and Average Order Value (AOV)
- Customer review analysis
- Impact of delivery delays on ratings
- Top product categories by revenue

Queries are written step-by-step with comments to clearly explain the logic and business intent.

---

## 📈 Key Insights
- Delivered orders account for the majority of platform revenue
- Late deliveries tend to receive lower average review scores
- A small set of product categories contributes a large share of total revenue
- Not all orders are successfully completed, highlighting real-world operational challenges
